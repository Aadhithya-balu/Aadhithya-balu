# 🚀 GitHub Profile README — Complete Portfolio Setup

## Step 1 — Create the Special Repository

Your special profile repository name MUST be exactly your GitHub username.

Example:

* GitHub username → `AadhithyaBalu`
* Repository name → `AadhithyaBalu`

Then:

* Set repository to **Public**
* Tick:

  * ✅ Add README

Once created, GitHub automatically shows that README on your profile page.
